# VR Homebrewers Museum

A browser-based preservation project based on the *Virtual Reality Homebrewer's Handbook* CD-ROM.

## Current implementation

- [Museum homepage](https://udeudeude.github.io/VR.Homebrewers.Museum/)
- [Cardboard model laboratory](https://udeudeude.github.io/VR.Homebrewers.Museum/cardboard.html)
- Bundled exhibit: `assets/vroom-box.obj`, converted from the disc's `VROOM/BOX.3D`.
- Touch rotation, stereoscopic side-by-side views, adjustable eye separation, optional phone orientation sensor, and user-supplied OBJ import.
- Experimental DOS program loader on homepage. **Not verified** to execute the disc's programs.

## Authenticity

The bundled VROOM Box retains the eight vertex positions and six polygon faces of the source. Its appearance, shading and presentation are generated by the modern viewer. The viewer is **not** the original VROOM runtime.

The source CD-ROM is not distributed here. Historical program licensing and redistribution rights require individual review.

## Important limitations

The Cardboard viewer has not been validated in a physical headset. It does not implement optical distortion correction or full Cardboard calibration. It currently displays isolated models rather than the complete original software environments. Original BRender, Virtus Player, Magic Carpet, and CyberMaxx demonstrations have **not** been ported or verified to run.

## Development priorities

1. Audit the CD-ROM's original executable formats, dependencies and documentation.
2. Convert and validate more complete historical models and scenes.
3. Implement Cardboard lens calibration and test on actual iPhone hardware.
4. Verify at least one original DOS demo in browser emulation before advertising compatibility.
5. Investigate stereo-capable source-based reconstruction of the original demonstrations.
